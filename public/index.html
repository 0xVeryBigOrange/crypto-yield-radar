像调用 OpenAI 一样调用

curl https://your-service.example.com/v1/chat/completions \
  -H "Authorization: Bearer sk-your-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai/gpt-4o-mini",
    "messages": [{"role": "user", "content": "hello"}]
  }'
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-key",
    base_url="https://your-service.example.com/v1",
)

stream = client.chat.completions.create(
    model="openai/gpt-4o-mini",
    messages=[{"role": "user", "content": "用一句话解释预付费 API。"}],
    stream=True,
    stream_options={"include_usage": True},
)
for event in stream:
    if event.choices and event.choices[0].delta.content:
        print(event.choices[0].delta.content, end="")

    问答

    可以调用哪些模型？

    上游目录里有价格的模型。默认上游是 OpenRouter，因此包含 GPT、Claude、Gemini、Grok、DeepSeek、Llama 等系列。请使用 /v1/models 返回的 ID，而不是品牌简称。

    一次请求怎么计费？

    转发前会按提示词长度和 max_tokens 估算费用，乘以缓存单价、倍率和安全缓冲（默认 1.25），并从余额里冻结。结束后优先采用上游返回的 cost，否则用 token 数乘缓存单价，再乘倍率，并把多冻的部分退回。流式请求会向上游要求返回 usage。如果已经输出内容但没有 usage，就按冻结金额结算。

    余额不够会怎样？

    请求会在转发前以 HTTP 402 拒绝，余额不会变成负数。

    充值怎么记到我的账户？

    USDT 和 USDC 按 1 美元记 1 美元。你在控制台提交交易哈希。服务端通过公开 RPC 核对：交易成功、包含一笔转到我们地址的受支持代币 Transfer、确认数足够、达到最低金额，并且这条链上的这个哈希没有入过账。第一个提交有效哈希的账户获得这笔额度。

    可以退款吗？

    已经消耗的调用不退。链上转账不可逆。未使用余额只能由运营方人工退回，本页不承诺自动退款。

    你们是 OpenAI 或 Anthropic 吗？

    不是。这是独立的转售服务，默认接在 OpenRouter 前面。可用性取决于上游。
